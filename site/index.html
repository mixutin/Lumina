01 / THE EXPERIENCE

Linux compatibility
without the ritual.

Lumina is being designed around sane defaults, recoverable state and visibility into what the launcher is actually doing.

MANAGED RUNTIME

UMU + Proton,
without Steam.

Lumina uses a dedicated compatibility environment and keeps runtime details out of your way until you actually need them.

lumina / runtime

› host linux / x86_64

› vulkan ready

› umu available

› prefix managed

A

OFFICIAL SOFTWARE

HoYoPlay stays in control.

Lumina does not redistribute the game, replace updates or patch protected game and anti-cheat files.

B

RECOVERABLE

Logs you can actually use.

Runtime health, prefix state and launch logs are surfaced directly instead of hiding failures behind a spinner.

C

DISTRIBUTION

Built for the Linux ecosystem.

Automated releases target portable AppImage plus Debian- and RPM-family packages, with more formats planned.

DESIGN

Looks like an app.
Not a setup script.

Native desktop shell. Fast Rust backend. Clean diagnostics. A UI designed for Linux gaming rather than terminal archaeology.
